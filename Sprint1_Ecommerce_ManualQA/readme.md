## Sprint 1 — E-commerce Manual QA

Manual QA sprint focused on testing the core functionality of an e-commerce web application using an Agile workflow and ISTQB-based test design techniques.

**Application:** [nopCommerce Demo Store](https://demo.nopcommerce.com/)

## Sprint Goal:

Validate the main customer journeys, identify defects, and assess the overall quality of the application.

## Scope
- Registration & Login
- Product Search & Navigation
- Product Details
- Shopping Cart
- Wishlist
- Checkout & Order Placement
- Form Validation

## Testing Approach

**Testing:** Functional · Smoke · Exploratory · Negative

**Test Design:** Equivalence Partitioning · Boundary Value Analysis · Decision Tables · State Transition Testing · Error Guessing

`Jira` · `GitLab` · `Chrome DevTools`
